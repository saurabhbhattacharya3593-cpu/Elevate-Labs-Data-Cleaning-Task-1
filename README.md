# Elevate Labs — Task 1: Data Cleaning and Preprocessing

## Selected dataset
**Netflix Movies and TV Shows** — one dataset selected from the options in the internship task sheet.

- Kaggle source: https://www.kaggle.com/datasets/shivamb/netflix-shows
- Common CSV filename: `netflix_titles.csv`
- Tools: Python and Pandas

## Task objective
Prepare a raw dataset for analysis by identifying and handling missing values, duplicates, inconsistent text/date formats, column names, and data types.

## Project files
- `data_cleaning.py`: complete, runnable Pandas cleaning script.
- `data_cleaning.ipynb`: step-by-step notebook for learning and demonstration.
- `requirements.txt`: Python dependency list.
- `netflix_titles.csv`: raw dataset, saved by the script on first run (or downloaded manually from Kaggle).
- `netflix_cleaned.csv`: cleaned dataset generated by the script.
- `cleaning_summary.txt`: actual before/after counts and changes, generated by the script.

## Run locally
1. Download `netflix_titles.csv` from the Kaggle link above and put it in this folder. (Alternatively, the script attempts to download a public mirror.)
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python data_cleaning.py`
4. Check the generated `netflix_cleaned.csv` and `cleaning_summary.txt`.

## Cleaning workflow
1. Inspect dimensions, data types, missing values, and duplicates.
2. Standardize column names (lowercase, underscores).
3. Trim whitespace and treat blank text as missing.
4. Remove exact duplicate records.
5. Parse `date_added` as datetime.
6. Convert `release_year` to nullable integer.
7. Standardize categorical labels such as `type` and `rating`.
8. Parse `duration` into numeric value and unit columns.
9. Fill selected descriptive fields (`director`, `cast`, `country`, `rating`) with `Unknown`.
10. Keep unknown dates/durations missing instead of fabricating data.
11. Export cleaned CSV and a summary report with actual calculated counts.

## Important
The summary report is generated from the actual input file when the script runs. Do not claim counts until you have run the script. This project covers **one dataset only**, as instructed.
